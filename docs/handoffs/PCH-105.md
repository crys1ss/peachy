- Fixed PCH-103 review items:

  - QMainWindow with native title bar, min size 760x520, default size 1100x720.
  - Geometry persistence to settings.main_window_geometry.
  - Close-to-tray handling respecting settings.close_to_tray.
  - Calls core.win32.set_dark_title_bar and set_backdrop safely via hasattr for Track B compatibility.

- Created `ui/sidebar.py`:
  - BrandHeader with BrandOrb, 'peachy' wordmark, and collapse toggle button.
  - Prominent 'New chat' button (Ctrl+N).
  - Search field with 150 ms debounce QTimer, Esc to clear (Ctrl+F).
  - ConversationList (QListView) with custom ConversationDelegate:
    - Section headers ('Pinned', 'Today', 'Yesterday', etc.) using history.grouping.
    - Title (1 line elided), preview (1 line in text_tertiary), relative timestamp.
    - 2 px vertical accent gradient marker at left edge for active conversation.
    - Hover menu with Rename, Pin/Unpin, Export, and Delete with confirmation.
  - Animated collapse/expand (264 px to 64 px) using ui.motion, persisting state to settings.sidebar_collapsed.
  - Sidebar footer with display name profile chip and Settings gear button.
- Created `ui/welcome_view.py`:
  - Hero BrandOrb (48 px).
  - Time-of-day greeting ("Good morning / afternoon / evening / night, <display_name>").
  - Subline: "Ask anything, or snip your screen with Ctrl+Shift+Space".
  - 2x2 clickable suggestion cards ("Explain a screenshot", "Debug this error", "Summarise a page", "Draft a reply").
  - Centred composer wrapper (max 680 px) with subtle entrance animation.
  - "Keep your chats?" opt-in history card shown when save_history_prompted is False; choice persists to settings.
- Created `ui/composer.py`:
  - Auto-expanding text input (44 px base up to 200 px).
  - Enter to send, Shift+Enter for newline, Up arrow in empty composer to edit last message.
  - Attach button with dropdown menu ("Upload image…", "Snip screen", "Paste image").
  - Clipboard image paste (Ctrl+V) and drag-and-drop image file support.
  - Enforces up to 4 images and 20 MB total limit with toast notifications on violation.
  - 56 px image thumbnail pills with remove (x) buttons.
  - Short/Detailed answer length toggle chip.
  - Circular 32 px send button with 135 deg accent -> accent_2 gradient, converting to stop square while busy.
- Shortcuts wired: Ctrl+N, Ctrl+F, Ctrl+B, Esc, Ctrl+Up/Down.
