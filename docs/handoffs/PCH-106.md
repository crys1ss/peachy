### Done:
1. **Streaming Provider & Model Discovery (`ai/provider.py`, `ai/gemini_provider.py`)**:
   - Implemented `ask_stream(images: list[bytes], question: str, history: Optional[list], answer_length: str, system_instruction: Optional[str]) -> Generator[str, None, Optional[dict[str, int]]]`.
   - Used Google GenAI Python SDK streaming API: `client.models.generate_content_stream`. (Official reference: `https://googleapis.github.io/python-genai/`).
   - Explicitly configured `automatic_function_calling=AutomaticFunctionCallingConfig(disable=True)`.
   - Strict fallback rule: fallback to the next model in `FALLBACK_MODELS` occurs ONLY before the first chunk is yielded. Once any chunk has been emitted, errors end the stream immediately without fallback and re-raise mapped `ProviderError`.
   - Usage metadata (`prompt_tokens`, `output_tokens`, `total_tokens`) captured from the final stream chunk and recorded on `provider.last_usage_metadata`.
   - Added `SYSTEM_INSTRUCTION_CHAT` for the main chat window (helpful, concise, markdown formatting without conversational filler) while preserving `SYSTEM_INSTRUCTION` for the overlay popup.
   - Added `list_models() -> List[str]` querying `client.models.list()` filtering models supporting `generateContent`, with a reliable static fallback list on any error.
   - `BaseAIProvider` provides a default `ask_stream` implementation wrapping `ask` to maintain 100% backward compatibility with all test doubles.

2. **Async Stream Worker (`core/stream_worker.py`)**:
   - `StreamWorker(QThread)` executing `ask_stream` asynchronously.
   - Emits signals: `chunk(request_id: int, accumulated_text: str)`, `finished(request_id: int, full_text: str, usage_metadata: dict)`, `failed(request_id: int, error_kind: str, user_message: str)`.
   - Thread-safe watchdog timeout: enforces a 20-second threshold without incoming chunks (`queue.Queue.get(timeout=20.0)`), emitting `"offline"` error on timeout.
   - Graceful cancellation (`cancel()`) ensuring stopped workers clean up promptly without emitting post-stop chunks.
   - Privacy-safe logging: log messages record chunk counts, timing, and token metrics; never prompt text.

3. **ChatSession Controller (`core/chat_session.py`)**:
   - Full implementation of the `ChatSession` contract in REDESIGN.md §7.
   - Signals: `conversation_started(int, str)`, `conversation_loaded(int, list)`, `title_changed(int, str)`, `message_added(dict)`, `stream_started(int)`, `stream_chunk(int, str)`, `stream_finished(int, dict)`, `stream_failed(int, str, str)`, `conversations_changed()`, `status_changed(str)`.
   - `build_context_history()` implements context restoration rules: caps to last 40 turns, character count capped at 60k going backwards from the newest message. Re-sends image bytes ONLY for the latest user turn with data, replacing older user images with `\n[image omitted]`.
   - Off-thread database persistence on `HistoryDbWorker`.
   - Respects `settings.save_history` (persists conversation when True, operates in-memory when False).
   - Respects `settings.save_thumbnails` (stores attachment thumbnail and full bytes when True, isolates full bytes when False).
   - AI conversation title generation: triggers non-blocking background title generation after the first assistant answer, updating `title` in DB and emitting `title_changed` (never overwriting if `title_locked=1`).
   - `regenerate()`: drops latest assistant turn and re-requests response.
   - `edit_and_resend(message_id, new_prompt)`: truncates messages from `message_id` onward in DB and streams new prompt.
   - `stop()`: immediately stops streaming and saves assistant turn with status `"stopped"` with whatever partial text was generated.

4. **Win32 DWM Title Bar & Backdrop (`core/win32.py`)**:
   - `set_dark_title_bar(hwnd: int, dark: bool) -> bool`: calls `DwmSetWindowAttribute` with `DWMWA_USE_IMMERSIVE_DARK_MODE` (20), falling back to 19 for older Windows 10 builds (1903/1909), and safe no-op returning `False` on unsupported platforms.
   - `set_backdrop(hwnd: int, kind: str | int = "mica") -> bool`: calls `DwmSetWindowAttribute` with `DWMWA_SYSTEMBACKDROP_TYPE` (38) supporting `"mica"`, `"acrylic"`, `"tabbed"`, `"auto"`, and `"none"`.

5. **Demo CLI Flag (`app.py`)**:
